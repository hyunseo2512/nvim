# Neovim 설정 (My Custom Neovim Config)

이 설정은 C언어와 Python 개발에 최적화된 Neovim 환경입니다.  
초보자도 쉽게 사용할 수 있도록 한글 주석과 직관적인 단축키를 제공합니다.

---

## 디렉토리 구조

```
~/.config/nvim
├── init.lua              # 진입점 (설정 로드 시작)
├── lazy-lock.json        # 플러그인 버전 잠금 파일
├── README.md             # 사용 설명서 (현재 파일)
└── lua
    ├── config            # 기본 설정
    │   ├── keymaps.lua   # 단축키 설정
    │   ├── lazy.lua      # 플러그인 매니저 설정
    │   └── options.lua   # 에디터 옵션 (줄 번호 등)
    └── plugins           # 플러그인별 상세 설정
        ├── colorscheme.lua   # 테마
        ├── cmp.lua           # 자동완성
        ├── formatting.lua    # 코드 포매팅
        ├── lsp.lua           # 언어 서버 (LSP)
        ├── neo-tree.lua      # 파일 탐색기
        ├── treesitter.lua    # 문법 강조
        └── ...
```

---

## 주요 기능

- **패키지 관리**: `lazy.nvim`을 사용하여 빠르고 편리하게 플러그인을 관리합니다.
- **강력한 자동완성**: `nvim-cmp`와 LSP를 연동하여 VSCode 수준의 자동완성을 제공합니다.
- **언어 지원**:
  - **C언어**: `clangd` (코드 분석), `clang-format` (포매팅)
  - **Python**: `pyright` (코드 분석), `black` (포매팅)
- **편의성**:
  - 시각적인 파일 탐색기 (`neo-tree`)
  - 빠른 파일/문자열 검색 (`telescope`)
  - 친절한 단축키 가이드 (`which-key`)

## ⌨️ 단축키 가이드 (Keymaps)

모든 사용자 지정 단축키는 **스페이스바 (`<Space>`)** 를 누른 후 시작합니다.
(이 키를 **Leader Key**라고 부릅니다)

### 기본 조작

| 키 입력     | 동작          | 설명                                          |
| :---------- | :------------ | :-------------------------------------------- |
| `jk`        | **ESC**       | 입력(Insert) 모드에서 누르면 일반 모드로 나감 |
| `<Space>w`  | **저장**      | 현재 파일 저장 (`:w`)                         |
| `<Space>q`  | **종료**      | Neovim 종료 (`:q`)                            |
| `<Space>bd` | **버퍼 닫기** | 현재 탭 닫기                                  |

### 파일 관리

| 키 입력     | 동작            | 설명                            |
| :---------- | :-------------- | :------------------------------ |
| `<Space>e`  | **탐색기 토글** | 좌측 파일 트리 열기/닫기        |
| `<Space>ff` | **파일 찾기**   | 파일 이름으로 검색 (Find Files) |
| `<Space>fs` | **내용 검색**   | 파일 내 문자열 검색 (Live Grep) |
| `<Space>fr` | **최근 파일**   | 최근 열었던 파일 목록           |

### 코드 분석 (LSP)

커서를 코드(변수, 함수 등) 위에 두고 입력하세요.
| 키 입력 | 동작 | 설명 |
| :--- | :--- | :--- |
| `gd` | **정의로 이동** | 변수/함수가 정의된 곳으로 점프 |
| `gr` | **참조 찾기** | 이 변수가 사용된 모든 곳 검색 |
| `K` | **도움말 보기** | 함수 설명이나 문서 팝업 표시 |
| `<Space>rn` | **이름 변경** | 변수명을 일괄 변경 (Rename) |
| `<Space>mp` | **포매팅** | 코드 줄 맞춤 (Format) |

## 트러블슈팅

### 1. 아이콘이 깨져 보이나요?

파일 탐색기 등의 아이콘이 `□`로 보인다면 **Nerd Font**가 필요합니다.
터미널 설정에서 `Hack Nerd Font` 또는 `D2Coding Ligature` 같은 폰트를 적용해주세요.

### 2. LSP가 동작하지 않나요?

`:Mason` 명령어를 입력하여 필요한 서버(`clangd`, `pyright`)가 설치되어 있는지(녹색 체크) 확인하세요.
설치되지 않았다면 자동으로 설치가 시도되지만, 실패 시 `i` 키를 눌러 수동으로 설치할 수 있습니다.

### 3. 상태 확인

설정에 문제가 생기면 아래 명령어로 진단할 수 있습니다.

```vim
:checkhealth
```
